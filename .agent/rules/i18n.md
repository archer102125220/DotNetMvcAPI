# Localization / i18n

This project uses the native `Microsoft.AspNetCore.Mvc.Localization` framework for backend translation.

## 1. Backend (Controllers & Services)
- Inject `IStringLocalizer<SharedResource>` or a specific localizer via dependency injection to translate API response messages or error messages.

```csharp
[ApiController]
[Route("api/[controller]")]
public class UsersController : ControllerBase
{
    private readonly IStringLocalizer<SharedResource> _localizer;

    public UsersController(IStringLocalizer<SharedResource> localizer)
    {
        _localizer = localizer;
    }

    [HttpGet("welcome")]
    public IActionResult GetWelcomeMessage()
    {
        return Ok(new { Message = _localizer["WelcomeMessage"].Value });
    }
}
```

## 2. Data Annotations (DTOs)
- Use `ErrorMessageResourceName` and `ErrorMessageResourceType` for model validation attributes so errors are localized automatically by the framework.

```csharp
public class CreateUserRequest
{
    [Required(ErrorMessageResourceName = "RequiredError", ErrorMessageResourceType = typeof(SharedResource))]
    public string Name { get; set; } = string.Empty;
}
```

## 3. Resource Files (.resx)
- Localization strings are stored in `.resx` files (e.g., `SharedResource.en.resx`, `SharedResource.zh-TW.resx`) in the `Resources/` folder.
- Ensure keys exactly match between your code and the `.resx` files.
